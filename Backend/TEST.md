Este documento descreve a estratégia de testes unitários e de integração para o servidor Backend.

## 🛠️ Ferramentas Utilizadas

* **Test Runner:** [Jest](https://jestjs.io/)
* **Testes de API (HTTP):** [Supertest](https://github.com/visionmedia/supertest)

## 🏃 Como Executar os Testes

1.  Garanta que o servidor **não** esteja rodando (`npm run dev` deve estar parado).
2.  Na raiz da pasta `/Backend`, execute o comando:

> npm test
