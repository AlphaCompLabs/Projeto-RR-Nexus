CONHEÇA NOSSO PROJETO

Este projeto demonstra uma arquitetura de aplicação web distribuída, projetada para escalabilidade e alta disponibilidade. O sistema utiliza balanceamento de carga via DNS Round Robin (RR DNS) para distribuir as requisições de usuários entre três servidores de aplicação distintos.

A solução implementa um mecanismo de sessão centralizada para resolver o desafio de estado. Isso garante que o usuário permaneça autenticado independentemente de qual servidor o balanceador DNS direcione sua conexão.
